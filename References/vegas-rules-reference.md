# Vegas 信号规则参考

来源：V12 `signal_rules.py`。此文档是规则说明，不是可执行算法副本。

## 均线定义
- 过滤线：EMA12（1H）。
- 中锋：EMA144 + EMA169（4H）。
- 红峰：EMA576 + EMA676（4H）。

## 周期与流程
1. 观察期：4H K 线触碰中锋或红峰区域，进入观察期。
2. 信号期：触碰发生后，后续 1H K 线收盘相对 1H EMA12 过滤线确认。
3. 触碰所在的 1H K 线本身不作为确认信号。
4. 多空判断由收盘位于 EMA12 上方或下方决定；V12 内部保留方向字段。
5. 中锋、红峰同一根 1H 同向触发时合并为一条信号。
