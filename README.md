# VEGAS Media Library

固定视觉素材、界面模板与技术参考资料库。

本仓库只保存可复用的静态素材和说明文档，不承载 V4/V12 的运行时代码、动态信号、密钥或状态文件。

## 来源与边界

- V4 来源：`MraJJqq/vegas-octopus-v4`
- V12 来源：`MraJJqq/v12`
- 正式系统保持独立；本仓库仅保存副本和静态规范。
- V4、V12 的任何文件均不因本仓库整理而被修改。

## 目录

- `Brand/`：VEGAS 品牌标识与应用图标
- `Logos/`：27 个品种 SVG 标识
- `Cards/`：行情卡片视觉模板
- `Charts/`：K 线与 EMA 配色规范
- `UI/`：颜色、字体与界面视觉规范
- `Templates/`：Bark 通知展示模板
- `References/`：品种清单、信号数据接口和 Vegas 规则说明
